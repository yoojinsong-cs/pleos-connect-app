# SAI 통합 프로젝트

Android Studio에서 이 폴더 자체를 열고 Gradle Sync 후 `app` 모듈을 실행하세요.
기존 프로젝트 안의 `app/src/main`에 이 전체 폴더를 중첩해서 넣지 마세요.

## 구성

- 앱 아이콘: 첨부한 SAI 아이콘과 동일한 기존 이미지.
- 홈: `Atri님, 잠시 쉬어 가요`, SAI 시작하기, 이번 주 릴렉스/냅핑/각성 각각의 완료 횟수.
- 시작하기 → 릴렉스/냅핑/각성 선택.
- 릴렉스: 6개 배경음 테마, 싱잉볼 24초(8초 간격 3회), 5분 호흡·어깨·목·가슴 안내. Pleos TTS 추가. 원본의 5배 테스트 속도 대신 실제 시간을 사용합니다.
- 냅핑: 10/15/20/30분 또는 직접 입력, ASMR 2종, 단계별 화면 밝기, 시간 종료 시 `SaiNapLink`로 각성 자동 전환.
- 각성: 원본의 3분 안내·글레오 대화 처리·음소거·종료 및 다음 일정 안내 흐름 유지. 홈에서 단독 실행 가능.
- 모든 진행 화면은 각성 모드의 동일한 XML, 버튼, 로고, 폰트 크기, 원형 끝점 진행바를 사용합니다.
- 진행바 색: 릴렉스 초록 / 냅핑 파랑 / 각성 베이지. 다른 UI의 기본 색은 유지합니다.
- 애니메이션 영역 높이는 안내 문구와 하단 영역의 실제 측정 높이를 제외한 남은 공간으로 계산합니다. 애니메이션은 이 영역 내부에 비율을 유지해 맞춥니다. 글씨나 진행바 위에 그리지 않습니다.
- 음소거는 해당 모드의 배경음/싱잉볼/음성 안내에 함께 적용됩니다.

## 일정과 글레오

냅핑 설정 화면 또는 냅핑 중 다음과 같이 요청합니다.

> 사이에 다음 일정 오후 두 시 반 면접으로 저장해 줘.

공통 `SET_NEXT_SCHEDULE` 동작이 앱 내부 파일 `sai_next_schedule.json`을 원자적으로 저장합니다.
냅핑과 각성은 같은 앱 ID와 저장소를 사용하므로 별도 복사 없이 공유합니다.
일정을 바꾸는 요청도 같은 파일에 반영하며, 각성 종료 시 최신 저장값을 읽습니다.
오전/오후가 빠진 모호한 한국어 시간은 글레오가 다시 확인하도록 원본 처리 방식을 유지합니다.
실제 음성 대화에는 Pleos 에뮬레이터의 글레오 및 앱 동작 스키마 등록이 필요합니다. 스키마는 `app/src/main/assets/schema.json`입니다.

일정 데이터 형식:

```json
{"version":1,"time":"14:30","title":"면접","savedAtEpochMillis":0}
```

예시의 일정이 자동으로 저장되지는 않습니다.

## 완료 횟수

- 릴렉스 정상 완료: 릴렉스 +1.
- 냅핑 시간이 정상 종료: 냅핑 +1 후 각성 시작.
- 이어지는 각성 정상 완료: 각성 +1.
- 각성 단독 정상 완료: 각성 +1.
- X, 뒤로가기, 차량 안전 중단은 진행 중 모드의 횟수를 추가하지 않습니다.
- 세션 ID를 DB 기본키로 사용하여 같은 완료 콜백이 중복 집계되지 않습니다.
- 이번 주는 기기 현지 날짜의 월요일~일요일입니다.

## 개발 환경

- 앱 ID/네임스페이스: `com.example.hyundaiappproject`
- compileSdk 37 / targetSdk 35 / minSdk 28
- AGP 9.5.0 / Gradle 9.6.0: 제공된 릴렉스 프로젝트의 환경 사용.
- Vehicle 2.3.2 / TextToSpeech 3.3.1: 제공된 소스와 동일한 SDK.
- 별도 Lottie 패키지 없이 각성 소스의 전용 JSON 렌더러를 확장합니다.
- 일반 휴대폰 에뮬레이터 대신 P단과 Pleos 서비스를 지원하는 차량 에뮬레이터를 사용하세요.
- 차량 API 지원 여부에 따라 지원되는 제어만 적용됩니다. 각성 원본에 있던 차량 동작 안내 문구를 실제 차량 제어 전체의 검증 결과로 해석하지 마세요.

## 확인 범위와 남은 확인

- 실제 SDK JAR와 Android 플랫폼 JAR를 사용한 전체 Kotlin 소스 컴파일 검사 통과.
- AAPT2 리소스 컴파일·링크 검사 통과.
- 전체 Gradle APK 빌드는 작업 환경의 Gradle 데몬 연결 실패로 완료하지 못했습니다.
- 에뮬레이터에서의 최종 화면, TTS/글레오 대화, 실제 시간 경과에 따른 자동 전환은 실행 확인이 필요합니다.
- Claude 애니메이션 링크는 작업 환경에서 접근하지 못했습니다. 현재는 제공된 ZIP의 `sai_bowl_loop.json`, `sai_relax_loop.json`, `sai_nap_loop.json`, `sai_awaken_loop.json`을 사용합니다. 링크의 애니메이션과 동일하다고 확인한 상태가 아닙니다. 정확한 교체에는 원본 GIF 또는 JSON 파일이 필요합니다.

## 실행 후 확인할 순서

1. 홈에 Atri님과 모드별 0회 또는 기존 기록이 표시되는지 확인합니다.
2. 릴렉스 테마를 선택하고 싱잉볼→4개 안내 단계→완료를 확인합니다.
3. 냅핑 시간을 직접 1분으로 설정하고 글레오에게 일정을 저장합니다.
4. 1분 뒤 각성이 한 번만 시작되고 ASMR이 중지되는지 확인합니다.
5. 각성 종료 시 저장한 일정이 안내되고 냅핑/각성 횟수가 각각 1 증가하는지 확인합니다.
6. 각성 단독 실행과 X/뒤로가기 종료의 횟수 정책을 확인합니다.
7. 작은 창과 큰 글꼴에서도 그래픽이 글씨와 진행바를 침범하지 않는지 확인합니다.
